My Projects

Here are some of the projects I have worked on as part of my academic journey and my interest in software development, artificial intelligence, and real-world problem solving.

1. Smart Attendance System

The Smart Attendance System is a face-recognition based application developed to simplify and automate the process of recording student attendance. The system uses a camera to identify registered students and automatically records their name, date, and time of attendance. It can also identify late arrivals and provide notifications when required. The project was developed to reduce manual attendance work, improve accuracy, and provide a more convenient solution for teachers and students.

Technologies: Python, OpenCV, Face Recognition, SQL, HTML, CSS, JavaScript

2. Santali Translator & Tutor

The Santali Translator & Tutor is an AI-powered application designed to help people communicate and learn the Santali language. The application supports text and speech-based translation and provides interactive learning features for users who want to improve their Santali language skills. It combines speech recognition, translation, and AI-based tutoring to create a more accessible language-learning experience. The project focuses on using modern AI technologies to support regional and less-resourced languages.

Technologies: Flutter, Python, FastAPI, AI APIs, Speech Recognition, Natural Language Processing

3. Personal AI Assistant

The Personal AI Assistant is an ongoing project inspired by the idea of creating a voice-based digital assistant. The system is designed to understand user commands, process requests using AI, and provide useful responses. The project explores concepts such as natural language processing, voice interaction, API integration, and automation. It is also helping me develop a deeper understanding of how AI-powered applications can interact with users and perform practical tasks.

Technologies: Python, Artificial Intelligence, APIs, Natural Language Processing, Voice Recognition
